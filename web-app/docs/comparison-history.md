# รายชื่อและปีการศึกษา

หน้าเปรียบเทียบรับปีการศึกษา พ.ศ. 2500–2700 พร้อม PDF และบันทึกผลใหม่ใน comparison_reports ทุกครั้ง ไม่ทับชุดเก่า ไม่เก็บ PDF ต้นฉบับ ปีเป็นปีของรายชื่อผู้สอบผ่านที่ Admin ระบุ ส่วน visitors/applications เป็นข้อมูลทุกปี ณ เวลาอัปโหลด เพื่อรักษาความหมายของคำขอ “ทั้งหมด” ไม่ใช่กลุ่มผู้สมัครเฉพาะปี รายชื่อและเปอร์เซ็นต์เป็น snapshot ไม่อัปเดตเองเมื่อมีผู้เข้าชมใหม่

สามช่องแสดงแถวรายชื่อทั้งหมดรวมชื่อซ้ำและชื่อไม่ครบ พร้อมค้นหา/แบ่งหน้า แถวที่อ่านจาก PDF ได้ไม่ใช่การรับรองว่าครบทั้งเอกสาร OCR และแถวไม่ชัดอยู่แยกตามเดิม เปอร์เซ็นต์ยังใช้เฉพาะชื่อครบแบบไม่ซ้ำ จึงอาจไม่เท่าจำนวนรายการในสามช่อง

Dashboard และหน้าเปรียบเทียบมีตัวเลือกปีและชุดอัปโหลด แสดงชื่อไฟล์ วันที่และเวลาอัปโหลด ผลก่อนเพิ่มฟีเจอร์ไม่ได้ถูกเก็บจึงต้องอัปโหลดใหม่ สิทธิ์อ่านเฉพาะ Admin ทุกสาขา สิทธิ์บันทึกต้อง can_edit=1 การอ่านตั้ง Cache-Control no-store ไม่มี API สาธารณะ รายชื่อเป็นข้อมูลส่วนบุคคล ควรกำหนดอายุเก็บและการลบตามนโยบายหน่วยงานก่อนใช้งานระยะยาว
