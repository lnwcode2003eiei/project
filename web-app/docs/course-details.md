# ข้อมูลเพิ่มเติมของหน้าสาขา

ทุกหน้าสาขาใช้ `CourseDetails` และเมนูลิงก์หัวข้อร่วมกัน โดยแยกข้อมูลด้วย `saka_path` ทั้ง 10 สาขา

## วิธีแก้ไข

เข้า Admin → จัดการหน้าสาขา → เลือกสาขา → **แก้ไขข้อมูลเพิ่มเติมของสาขา** (แสดงด้านบนทันที)
เลือกหนึ่งใน 4 หมวด: **มาตรฐานการเรียนรู้ / TQF และ PLO**, **ปรัชญาและวัตถุประสงค์**, **สิ่งสนับสนุนการเรียนการสอน**, **การติดต่อ**
สลับหมวดได้โดยข้อมูลที่กรอกยังอยู่ กดบันทึกครั้งเดียวเพื่อบันทึกข้อมูลเพิ่มเติมทุกหมวดของสาขาที่เลือก
กรอกปรัชญา มาตรฐาน/PLO เพิ่มรายการวัตถุประสงค์ เอกสาร สิ่งสนับสนุน หรือข้อมูลติดต่อ
แต่ละรายการรองรับชื่อ รายละเอียด ไอคอน และลิงก์ HTTP(S)
กด **บันทึกข้อมูลเพิ่มเติมของสาขา** (แยกจากปุ่มบันทึกข้อมูลหลักสูตรเดิม)
รีเฟรชหน้าสาธารณะเพื่อเห็นข้อมูลที่บันทึก

ไม่มีการสร้างข้อมูลวิชาการ/ทุนการศึกษาขึ้นเอง หากยังไม่กรอก จะแสดงข้อความอยู่ระหว่างจัดเตรียมข้อมูล
ลบรายการในฟอร์มแล้วต้องกดบันทึกจึงจะมีผล

## ฐานข้อมูลและ API

- `course_details`: `saka_path` (primary key), `content` (JSON), `updated_at`
- สร้างตารางแบบ `CREATE TABLE IF NOT EXISTS` เมื่อเรียก API ครั้งแรก ไม่แก้ไข/ลบข้อมูล `course_info`
- GET `/api/course-details/:slug` เป็นข้อมูลสาธารณะ
- PUT `/api/course-details/:slug` ต้องใช้ token Admin และสิทธิ์แก้ไขสาขานั้น หรือสิทธิ์ทุกสาขา
- ตรวจการมีอยู่ของสาขา รูปแบบรายการ ขนาดข้อความ อีเมล และลิงก์ก่อนบันทึก
- สำรองตารางนี้พร้อมฐานข้อมูลเมื่อย้ายขึ้นเซิร์ฟเวอร์ บัญชี DB ต้องมีสิทธิ์สร้างตาราง

## ทดสอบในเครื่อง

```sh
node --test server/course-details.test.js
npm run build
docker compose -f docker-compose.yml -f compose.local.yml up -d --build --no-deps frontend backend
```

ไม่ควรใช้ `compose.local.yml` บนเซิร์ฟเวอร์จริงโดยไม่ตรวจการตั้งค่า proxy/port ก่อน
