# โครงสร้างฐานข้อมูล `university_web`

ภาพชุดนี้แยกตารางออกเป็น 5 ส่วนเพื่ออ่านง่าย โดยใช้สีและคอลัมน์เดียวกันทุกภาพ: ชื่อฟิลด์, ชนิดข้อมูล และข้อกำหนดสำคัญ

| ส่วน | หน้าที่ |
| --- | --- |
| `visitors` | เก็บชื่อ สถานะ และเวลาของผู้เข้าชมเว็บไซต์ |
| `users` | เก็บบัญชีผู้ดูแล สิทธิ์แก้ไข และขอบเขตสาขาที่ดูแล |
| `news` | เก็บข่าว หมวดหมู่ เนื้อหา รูป และวันเผยแพร่ |
| `applications` | เก็บข้อมูลผู้สมัครและสาขาที่ต้องการสมัคร |
| `course_info` | เก็บรายละเอียดหลักสูตร รวมถึงข้อความ รูปภาพ และข้อมูล JSON ที่ใช้แสดงบนหน้าเว็บ |

## ความสัมพันธ์ระหว่างข้อมูล

โครงสร้างปัจจุบันยังไม่มี `Foreign Key` จริงระหว่างตาราง จึงไม่แสดงเส้นความสัมพันธ์แบบบังคับในภาพ

- `applications.major_name` ใช้เก็บชื่อสาขาเป็นข้อความ แต่ไม่ได้ผูกกับ `course_info.saka_path`
- `users.saka_path` ระบุขอบเขตสาขาที่ผู้ดูแลเข้าถึงได้ แต่ไม่ได้ผูกกับตารางหลักสูตร
- `visitors` และ `news` ทำงานเป็นข้อมูลอิสระ

`PK` คือ Primary Key และ `Auto Increment` คือเลขลำดับที่ระบบเพิ่มให้เอง
