# PDF หลักสูตร

Admin แต่ละสาขาอัปโหลด PDF ที่ไม่มีรหัสผ่าน (10 MB / 300 หน้า) เพื่อดึงข้อความด้วย Poppler และเสนอแถวรหัสวิชา/ชื่อหรือหมวดวิชา/หน่วยกิต ต้องตรวจเทียบก่อนเผยแพร่ รองรับข้อความที่มีช่องว่างแบ่งคอลัมน์ ไม่ใช่การรับรองว่าดึงครบทุกแถว ไม่รองรับ OCR ในรุ่นนี้และไม่สร้างข้อมูลที่หายไป แสดงข้อความต้นทางสูงสุด 100,000 ตัวอักษรและตารางสูงสุด 500 แถว

ไฟล์อยู่ใน MySQL ตาราง curriculum_pdf_files (รวมใน backup ฐานข้อมูล) ร่างเข้าถึงได้เฉพาะ Admin ที่มีสิทธิ์สาขา ตาราง curriculum_pdf_publications อ้างไฟล์ปัจจุบันและตารางที่ผ่านการตรวจแล้ว อัปโหลดไม่เปลี่ยนข้อมูลเผยแพร่ การบันทึกตรวจ version เพื่อป้องกันทับข้อมูลที่ผู้อื่นแก้แล้ว ไฟล์เก่าไม่ถูกลบและไม่เปิดสาธารณะหลังถูกแทนที่ ร่างที่ยกเลิกยังเก็บอยู่ ต้องวางนโยบายล้างร่างตามอายุภายหลัง ห้ามล้างไฟล์ที่ใช้งานโดยไม่ตรวจ

หน้า Admin เรียงส่วน PDF ตรงตำแหน่งหลักสูตร และใช้ CurriculumTable ร่วมกับเว็บจริง มีตารางแก้ไขและตัวอย่างก่อนเผยแพร่ ตารางเดิม/เทียบโอนอยู่ในส่วนพับเก็บ ไม่ถูกย้ายหรือลบ เมื่อเผยแพร่ PDF หน้าเว็บไซต์จะแสดงตาราง PDF แทนส่วนตารางเดิมของสาขานั้น (หนึ่งชุด PDF ต่อสาขา) หากต้องการแยก PDF 4 ปี/เทียบโอน ต้องเพิ่มการเลือกแผนภายหลัง

ทดสอบกับ PDF ตัวอย่างจริงก่อนใช้ production โดยเฉพาะตารางหลายคอลัมน์/หลายหน้า ใช้เอกสารที่อนุญาตให้เผยแพร่เท่านั้น ไม่มีการอัป Git หรือ deploy อัตโนมัติ
